# my-esp-libraries

Librerie locali condivise dal progetto.

## Librerie

- `CommonDebug`: macro di logging condizionate da `DEBUG`
- `DeviceProperties`: fetch e cache delle properties device
- `DeviceSetupManager`: lettura dei file di provisioning
- `EspOTA`: gestione aggiornamenti OTA
- `LiteWiFiManager`: provisioning Wi-Fi minimale
- `MQTTManager`: connessione MQTT con certificati provisionati
